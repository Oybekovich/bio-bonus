BIO-BONUS — YANGILANGAN DEMO

1) Ushbu ZIPni Extract All orqali to‘liq papkaga chiqaring.
2) BIO-BONUS-PWA papkasini oching.
3) START_BIO_BONUS.bat faylini ikki marta bosing.
4) Brauzerda http://localhost:8080 ochiladi.

ID oynasida telefon egasining o‘z 8 xonali ID raqami ko‘rsatiladi.
Blok paytida avval yig‘ilgan balans saqlanadi, lekin bonus do‘koni va kartaga chiqarish blok tugaguncha yopiq bo‘ladi.

Eslatma: bu demo. Akkauntlar va blok holati shu brauzer localStorage xotirasida saqlanadi. Haqiqiy mahsulotda blok va balans qoidalari serverda ham tekshirilishi shart. Haqiqiy tarozi, X-ray va bank to‘lovi ulanmagan.
